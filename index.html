ExamDNA

Reads a university exam question and maps its DNA.

Paste a question from the Logic course and ExamDNA returns a structured analysis: the topic, the skill the question really tests, its question family, the kind of answer it asks for and a difficulty score, each with a confidence level. A language model proposes the classification, then a strict pipeline checks it against a course vocabulary of 64 topics, 36 skills and 22 question families, repairs only what is safe to repair, and sends uncertain results to human review. Every prompt change is scored against a hand labeled gold set, so progress is measured instead of guessed.

Python, Pydantic, Claude API, FastAPI, YAML domain packs, pytest, mypy

022026Full stack product

NadlanEast

Looking for an apartment, but it works like a dating app.

A Hebrew real estate app that connects buyers, private sellers and realtors. Buyers set a budget, areas and must haves, then swipe through listings while a match score ranks every property: an AI match runs on the server with Gemini, and a built in scoring algorithm takes over if the AI is unavailable. Realtors are verified by license, sellers can boost listings, and there are chats, listing alerts, paid plans and an admin panel. The latest version is built for a pilot with real users and real listings, with hardened database permissions and strict security headers.

AlgoMentor AI

A coding interview coach that won't just hand you the answer.

You pick one of ten original algorithm problems and an AI interviewer asks for your approach before you write a single line. It pushes back with follow up questions, gives hints one step at a time (each hint costs points, like in a real interview), and ends with a scorecard on correctness, complexity and communication, plus the problem you should try next.

Built with
