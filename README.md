Live at [agamalonn.github.io](https://agamalonn.github.io/)

## Featured work

## How it's built

- One `index.html` with hand written HTML, CSS and vanilla JavaScript
- Self hosted fonts (Instrument Serif, Geist, Geist Mono) in `assets/fonts`
- Scroll reveals, a word by word statement, parallax, project previews on hover and animated product mockups, all respecting `prefers-reduced-motion`
- No build step, hosted on GitHub Pages

To preview locally, open `index.html` in a browser.
